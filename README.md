### 🚀 About Me

I specialize in **Tamil Natural Language Processing (NLP)**, **software and app development**, and **end-to-end digital localization**. My work bridges linguistic precision with modern web and software engineering to create intuitive, accessible, and native-feeling Tamil digital products.

- 🔭 **What I Do & Build:**
  - **App & Software Development:** Designing native-feeling Tamil applications, web tools, and software solutions
  - **Website Creation & Internationalization (i18n):** Building accessible, responsive websites engineered from the ground up for Tamil audiences
  - **App & UI/UX Localization (l10n):** Adapting mobile and web interfaces with natural, context-aware terminology
  - **Linguistic Engineering:** High-quality glossary standardization, translation quality assurance, and NLP dataset curation
- 🌱 **Currently Exploring:** Advanced Indic NLP pipelines, `iNLTK`, and modern web accessibility (a11y) frameworks
- 🤝 **Open to Collaborate on:**
  - Tamil software, mobile app, and web development projects
  - End-to-end mobile app localization and UI testing pipelines
  - Open-source Tamil datasets, parallel corpora, and community language tools
